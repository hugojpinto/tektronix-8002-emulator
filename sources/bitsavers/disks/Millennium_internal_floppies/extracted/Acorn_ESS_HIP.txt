1.0 MEMORY STRUCTURE

1.1 ACORN MEMORY STRUCTURE

     The ACORN processor has a 16K to 64K byte non expandable RAM memory

with parity.



1.2 ESS MASTER MEMORY STRUCTURE

     The  ESS master processor has a 16k to 48k byte non expandable  RAM

memory  with  parity.  When the top 16k byte of  the  memory  (addresses

C000H-FFFFH) are accessed the processor will access the multibus for the

memory  data.  There  is  a port on the card which allows the  16k  byte

window  onto  the  multibus to be placed in any 16K  byte  page  of  the

MULTIBUS 1M byte address range.



1.3 HIP MEMORY STRUCTURE

     The  HIP processor has a 16k to 64K byte non expandable ram  memory

with  parity.  This  memory is dual ported and may be accessed from  the

MULTIBUS as a 64k byte page of the MULTIBUS 1M byte address  range.  The

processor on this card views the local memory as being the in the first

64k  of the MULTIBUS address space.  When the processor accesses any  of

the  other  64k multibus pages the top 16K bytes of the memory page  are

assumed to be in the local memory.
