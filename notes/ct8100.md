# CT8100 CRT Terminal

The 8002's system terminal. Source: the CT8100 Users Manual, 070-2359-00 (1977; on bitsavers as
`pdf/tektronix/terminal/070-2359-00_CT8100-4023_77.pdf`, kept in
`sources/bitsavers/manuals/ct8100/`; a scan with no text layer). Its preface: "The CT 8100 is
similar to the TEKTRONIX 4023 Computer Display Terminal. Therefore, most instrument references
in this manual are to the TEKTRONIX 4023." The rest of the manual is the 4023 Users Manual.

## What TEKDOS relies on (Table 2-2, "ASCII Code Effect", pp. 2-7 to 2-10)
| Code | Effect |
|---|---|
| BS (08) | "Moves the cursor to the left one character. If the cursor is already at the left margin, the BS command has no effect." Not destructive |
| HT (09) | in DIRECT mode, "a non-destructive direct space, i.e. moves cursor right one space" (in buffer mode it tabs between form fields) |
| LF (0A) | down one line; past the 24th line the screen rolls up, in DIRECT. A CR with it is a strap option |
| CR (0D) | to the left margin; a line feed with it is a strap option |
| BEL (07) | "the bell-like tone from the speaker" |
| DEL (7F) | "Does not write or space" (p. 2-7) |

TEKDOS echoes a bare BS for the BACK SPACE key and the deleted character for RUB OUT (checked
with `-log`: `LDIX`, BS, `R` gives `4C 44 49 58 08 52`; with RUB OUT, `... 58 58 52`), as the
TEKDOS 3 booklet (070-2706) says: BACK SPACE deletes "but not display", RUB OUT "deletes and
displays". On the CT8100 a backspaced character stays on the screen until it is typed over.

## Documented, not modelled
Buffer mode and form fill-out (field attribute codes after US, Table 2-1), cursor addressing
(FS, X+32, Y+32), ESC FF (clear page), ESC SO / ESC SI (send page / transmittable fields),
ESC O (clear input), ESC ] (read cursor: GS X Y END), ESC BEL (hard copy), SO/SI (optional
rulings character set), the program time delays and fill characters (p. 2-6). TEKDOS sends
none of these; a user program could.
