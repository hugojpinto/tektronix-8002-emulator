# CT8100 CRT Terminal

The 8002's system terminal. Source: the CT8100 Users Manual, 070-2359-00 (1977; on bitsavers as
`pdf/tektronix/terminal/070-2359-00_CT8100-4023_77.pdf`, kept in
`sources/bitsavers/manuals/ct8100/`; a scan with no text layer). Its preface: "The CT 8100 is
similar to the TEKTRONIX 4023 Computer Display Terminal. Therefore, most instrument references
in this manual are to the TEKTRONIX 4023." The rest of the manual is the 4023 Users Manual.

## What TEKDOS relies on (Table 2-2, "ASCII Code Effect", pp. 2-7 to 2-10)
| Code | Effect |
|---|---|
| BS (08) | "Moves the cursor to the left one character. If the cursor is already at the left margin, the BS command has no effect." Not destructive |
| HT (09) | in DIRECT mode, "a non-destructive direct space, i.e. moves cursor right one space" (in buffer mode it tabs between form fields) |
| LF (0A) | down one line; past the 24th line the screen rolls up, in DIRECT. A CR with it is a strap option |
| CR (0D) | to the left margin; a line feed with it is a strap option |
| BEL (07) | "the bell-like tone from the speaker" |
| DEL (7F) | "Does not write or space" (p. 2-7) |

TEKDOS echoes a bare BS for the BACK SPACE key and the deleted character for RUB OUT (checked
with `-log`: `LDIX`, BS, `R` gives `4C 44 49 58 08 52`; with RUB OUT, `... 58 58 52`), as the
TEKDOS 3 booklet (070-2706) says: BACK SPACE deletes "but not display", RUB OUT "deletes and
displays". On the CT8100 a backspaced character stays on the screen until it is typed over.

## The keyboard (pp. 1-14, 1-15)
- **TTY LOCK**, a latching key: "All lower case characters are then displayed and/or
  transmitted as upper case characters, regardless of condition of SHIFT key." TEKDOS takes
  commands in upper case only (070-2706: "UPPERCASE words must be entered exactly as shown";
  `ldir` gives error 03, command file not found). Modelled (`-ttylock off`; GUI Cmd+U;
  monitor `T`). Scripted `-type` text is sent as written.
  **Its state is not documented:** the key latches mechanically ("Key must be pressed a second
  time to unlock"), so it stays as the last operator left it; no 8002 manual mentions it, and
  the CT8100's setup (p. 1-19) names only LOCAL/ON LINE, DIRECT/BUFFER and the auxiliary
  switches. On by default is a choice: TEKDOS needs upper case, and every session in the
  manuals is upper case, so an 8002 operator most likely kept it down (inferred).
- BACK SPACE: "Moves the cursor one character space to the left. Does not destroy data."
- TAB: "In Direct with echo, TAB causes cursor to move one space right."
- RUB OUT and BREAK: "The function of this key varies by computer system."

## Host features (pp. 2-2 to 2-12), modelled in DIRECT mode
- **LF DOES CR** strap set (p. 2-1, p. 2-8): LF also returns the carriage. TEKDOS echoes the
  RETURN key as LF and DC3, with no CR (checked with `-log`), so without the strap its next
  output starts where the command line ended. The lab's terminal must have had it (inferred from
  that echo). CR DOES LF is not set: TEKDOS ends its own lines with CR LF.
- **FS X Y**, cursor addressing: X = column + 32, Y = line + 32 (p. 2-4: column 18 of line 10
  is FS '2' '*').
- **ESC FF**, clear page: the screen cleared, the cursor home, "all Terminal logic is
  initialized". A plain FF does nothing ("performs a clear page function when preceded by ESC").
- **ESC ]**, read cursor: the terminal sends GS, X, Y, END; END is CR as standard (a strap can
  make it any control character).
- **US FAC**, display formatting (Table 2-1): the FAC is stored in the first position of its
  field and sets the field's look up to the next FAC or the end of the line. Rows of codes from
  `@`: white on black, black on white, blinking, blanked. Within a row: unprotected alpha,
  unprotected non-alpha, protected normal, protected dim, then the same four non-transmittable.
  The FAC's own position shows blank, and the cursor moves on past it (inferred).
- **ESC O** (also `o`, `/`), clear input: unprotected fields blanked (the terminal stores NULs).
- **SO / SI**, the optional rulings set for codes 32-63 (Fig. 2-2, Table 2-3): code = 32 + 6P +
  2S + T. Simple joins (P 0-2): P is the horizontal element (right half, across, left half), S the
  vertical (lower half, across, upper half), T single or double. Complex joins (P 3, 50-55): a
  double superior element across (T 0 horizontal, T 1 vertical) with a single inferior one of
  join type S. Single elements (P 4, 56-59). 60-63: upper block, full block, lower block, blank
  (extents read from the figure). The glyphs are drawn from the formula, not copied from the
  figure. Under SO a space is a ruling (┌), as Fig. 2-2 shows.
- **The cursor** does not blink on the standard terminal ("The standard 4023 does not blink the
  cursor unless the RESET key is pressed. The BLINK CURSOR strap … make[s] the cursor blink
  continuously", p. 2-2): steady in the GUI, `-cursor blink` for the strap. Blinking fields and
  the strapped cursor blink at 1 Hz (inferred).
- `emu/tests/ct8100_test.cpp` checks all of these (in `make test`).

## Documented, not modelled
BUFFER mode: form fill-out, keyboard editing in terminal memory (INSERT/DELETE line and
character, ERASE TO END, PAGE ERASE INPUT), VT (back tab, "does not work in DIRECT"), ESC SO and
ESC SI (send page / send transmittable fields), the prompt character; ESC BEL (hard copy: no hard
copy unit); the program time delays and fill characters (p. 2-6); local echo and LOCAL mode.
