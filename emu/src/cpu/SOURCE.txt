Changes made in this project are marked [tek8002] and listed here:
  i8085/i8085.*  a constructor flag selects MAME's i8080 variant (is_8085() false, jmp_taken 0,
               call_taken 6: what MAME's i8080_cpu_device subclass overrides), for the
               8080 Emulator Processor (2026-11-13).
  m6800/6800ops.hxx  TAP and RTI keep CC bits 7-6 set: they are not implemented on the
               6800 and always read as 1 (MC6800 data sheet, "Condition Code Register").
               Upstream stores the byte as is, so a TAP of 00 made TPA read 00. Found by
               the 6800 board's real SYSTEM PROM, whose dump reads CC with TPA (2026-11-13).
