Changes made in this project are marked [tek8002] and listed here:
  i8085/i8085.*  a constructor flag selects MAME's i8080 variant (is_8085() false, jmp_taken 0,
               call_taken 6: what MAME's i8080_cpu_device subclass overrides), for the
               8080 Emulator Processor (2026-11-13).
  i8085/i8085.cpp  in 8080 mode a conditional jump or call that is not taken still reads its
               two address bytes (it takes 3 machine cycles, 10/11 states, on the 8080A);
               upstream skips them, so the bus showed no operand reads. Millennium's 8080
               hardware analyzer test (DIP 4.4, D3A21) traces a JZ not taken with both
               reads (2026-11-15).
  m6800/m6800.*  generated: tools/port_m6800.py makes logerror() a macro that evaluates its
               arguments only when log_illegal is set. Upstream's illegal-opcode messages pass
               M_RDOP_ARG(PC-1), a bus read, which ran even with logging off and put a phantom
               read in the RTPA's trace (Millennium's 6800 hardware analyzer test, D3A30,
               2026-11-15). The TAP/RTI edit below is applied by the same script.
               TAP and CLI no longer run the next instruction inside themselves (upstream's
               way of holding off an IRQ for one instruction, execute_one()); step() honours a
               flag instead, so that each instruction is one step for the 6800 board's Debug
               logic (Millennium's 6800 FETCH test, DE221: PC next = PC + 1 after TAP and CLI).
  m6800/6800ops.hxx  TAP and RTI keep CC bits 7-6 set: they are not implemented on the
               6800 and always read as 1 (MC6800 data sheet, "Condition Code Register").
               Upstream stores the byte as is, so a TAP of 00 made TPA read 00. Found by
               the 6800 board's real SYSTEM PROM, whose dump reads CC with TPA (2026-11-13).
  s2650/s2650.cpp  RRL/RRR set or clear OVF only when rotating through the carry (WC=1); with
               WC=0 OVF is left alone. Upstream changes it on every rotate, as the 1975
               Signetics manual's note reads (p. 67-68). Millennium's MASTER CPU diagnostic
               (DIP 4.4, D0141), written for real 2650s, checks both: no OVF from rotates with
               WC=0 that flip bit 7, OVF from one with WC=1 (2026-11-15).
